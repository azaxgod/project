# Интеграция с Snowops Acts Service (EPIC 9)

## Обзор

Реализована интеграция с Snowops Acts Service для автоматической генерации актов выполненных работ (форма Р-1) по подрядчику.

## Архитектура

### 1. Сервисный слой

**`lib/services/acts/module.dart`**
- `actsDioProvider` - HTTP клиент с настройкой для Acts Service
- `actsCollectionProvider` - Provider для `ActsCollection`
- Base URL: `https://snowops-acts-service.onrender.com`
- JWT авторизация через interceptor
- Увеличенные таймауты (30 сек) для генерации PDF

**`lib/services/acts/collection/acts_collection.dart`**
- `ActsCollection` - класс для работы с Acts API
- `generateActPdf()` - метод генерации PDF акта
- Обработка ошибок с детальными сообщениями
- Динамическое изменение `responseType` для получения PDF байтов

### 2. Утилиты

**`lib/core/utils/file_downloader.dart`**
- `FileDownloader.downloadFile()` - универсальная утилита для скачивания файлов
- Поддержка веба (браузерное скачивание через `dart:html`)
- Поддержка мобильных платформ (сохранение в Downloads/Documents)
- Условные импорты для веба (`file_downloader_web.dart` / `file_downloader_stub.dart`)

### 3. UI компоненты

**`lib/modules/analytics/src/ui/screen/analytics_contracts_page.dart`**
- Добавлены фильтры по периоду для генерации акта
- Кнопка "Скачать акт (PDF)" в таблице контрактов
- Проверка ролей пользователя (только для AKIMAT_ADMIN, KGU_ZKH_ADMIN, CONTRACTOR_ADMIN)
- Индикация загрузки и обработка ошибок

## API Endpoint

### POST `/contracts/{contract_id}/acts/generate-pdf`

**Запрос:**
```json
{
  "period_start": "2025-01-01",
  "period_end": "2025-01-31"
}
```

**Ответ:**
- Content-Type: `application/pdf`
- Тело: байты PDF файла

**Ошибки:**
- `400` - Неверные параметры
- `403` - Нет доступа (роль или принадлежность контракта)
- `404` - Контракт не найден
- `422` - Нет валидных рейсов за период
- `500` - Ошибка сервера

## Роли и доступ

### Могут генерировать акты:
- **AKIMAT_ADMIN** - может скачать акт по любому контракту
- **KGU_ZKH_ADMIN** - может скачать акт по любому контракту
- **CONTRACTOR_ADMIN** - может скачать акт только по своим контрактам

### Не могут генерировать акты:
- **TOO_ADMIN** - кнопка не отображается
- **DRIVER** - кнопка не отображается

**Важно:** Проверка прав доступа выполняется на бэкенде. Фронт только скрывает/показывает кнопку для удобства.

## Использование

### На странице "Аналитика контрактов"

1. **Выбор периода:**
   - В блоке "Фильтры для генерации акта" выберите период работ
   - По умолчанию установлен текущий месяц

2. **Генерация акта:**
   - В таблице контрактов найдите нужный контракт
   - Нажмите кнопку скачивания (иконка загрузки) в колонке "Действия"
   - Дождитесь генерации PDF (показывается индикатор загрузки)
   - Файл автоматически скачается

3. **Имя файла:**
   - Формат: `akt-{contract_id}-{period_start}-{period_end}.pdf`
   - Пример: `akt-12345678-20250101-20250131.pdf`

## Обработка ошибок

### На фронте:
- Проверка выбранного периода перед запросом
- Индикатор загрузки во время генерации
- SnackBar с сообщением об успехе/ошибке
- Детальные сообщения об ошибках от API

### Типичные ошибки:
- **"Выберите период для генерации акта"** - не выбран период
- **"Forbidden (403)"** - нет прав доступа к контракту
- **"Unprocessable Entity (422)"** - нет валидных рейсов за период
- **"Connection timeout"** - проблемы с сетью или сервером

## Зависимости

Добавлены в `pubspec.yaml`:
- `path_provider: ^2.1.1` - для сохранения файлов на мобильных платформах

## Конфигурация

### Acts Service URL
Настроен в `lib/services/acts/module.dart`:
```dart
baseUrl: 'https://snowops-acts-service.onrender.com'
```

### Таймауты
- Connect: 30 секунд
- Receive: 30 секунд (PDF может генерироваться долго)
- Send: 15 секунд

## Безопасность

1. **JWT авторизация:**
   - Токен автоматически добавляется в заголовки через interceptor
   - Токен берется из `TokenStorage`

2. **Проверка ролей:**
   - На фронте: скрытие кнопки для неавторизованных ролей
   - На бэкенде: строгая проверка прав доступа

3. **Валидация данных:**
   - Проверка наличия периода перед запросом
   - Валидация формата дат на бэкенде

## Логирование

Все запросы к Acts API логируются:
- JWT токен (длина)
- URL и параметры запроса
- Размер ответа (PDF)
- Ошибки с деталями

## Примеры использования

### Генерация акта для контракта

```dart
final actsCollection = ref.read(actsCollectionProvider);
final pdfBytes = await actsCollection.generateActPdf(
  contractId: 'contract-id-123',
  periodStart: DateTime(2025, 1, 1),
  periodEnd: DateTime(2025, 1, 31),
);

await FileDownloader.downloadFile(
  bytes: pdfBytes,
  filename: 'akt-contract-20250101-20250131',
  extension: 'pdf',
);
```
