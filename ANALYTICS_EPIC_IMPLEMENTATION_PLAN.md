## 🛠 Технические детали

### Необходимые библиотеки

1. **Для графиков:**
   - `fl_chart` или `syncfusion_flutter_charts` - для графиков и диаграмм

2. **Для карт:**
   - `google_maps_flutter` или `flutter_map` - для отображения карт
   - `geojson` - для работы с GeoJSON данными

3. **Для экспорта:**
   - `excel` - для экспорта в Excel
   - `pdf` - для экспорта в PDF (опционально)

4. **Для таблиц:**
   - Использовать существующий `OrganizationsDataTable` или создать аналогичный компонент
