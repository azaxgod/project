# Диагностика ошибок Analytics API

## Ошибка 500 Internal Server Error

Если вы получаете ошибку 500 при запросе к `/analytics/dashboard` или другим endpoints, это означает проблему на стороне сервера.

### Что проверить:

1. **Логи приложения**
   - Откройте консоль разработчика (Flutter DevTools или терминал)
   - Проверьте логи с префиксом `Analytics API -` и `Analytics Dashboard -`
   - Убедитесь, что JWT токен передается (должно быть сообщение `JWT token added`)

2. **JWT токен**
   - Убедитесь, что пользователь авторизован
   - Проверьте, что токен не истек
   - Проверьте формат токена в логах

3. **Формат дат**
   - Даты должны быть в формате RFC 3339: `2025-11-10T05:09:39Z`
   - Проверьте логи: `Analytics Dashboard - from:` и `Analytics Dashboard - to:`

4. **Сервер**
   - Проверьте логи сервера `snowops-analytics-service.onrender.com`
   - Убедитесь, что база данных доступна
   - Проверьте, что все необходимые таблицы существуют

### Типичные причины ошибки 500:

1. **Проблемы с базой данных**
   - Отсутствие таблиц или materialized views
   - Проблемы с подключением к БД
   - Неправильные SQL запросы

2. **Проблемы с авторизацией**
   - Неверный формат JWT токена
   - Истекший токен
   - Отсутствие прав доступа (RLS)

3. **Проблемы с данными**
   - Отсутствие данных в базе
   - Некорректные данные в запросе
   - Проблемы с парсингом дат на сервере

### Как получить детальную информацию:

1. В приложении нажмите кнопку **"Детали"** при ошибке
2. Проверьте логи в консоли разработчика
3. Проверьте Network tab в браузере (для веб-версии)

### Примеры логов:

```
Analytics API - JWT token added (length: 234)
Analytics API - Request: GET https://snowops-analytics-service.onrender.com/analytics/dashboard
Analytics API - Query params: {from: 2025-11-10T05:09:39Z, to: 2025-11-17T05:09:39Z}
Analytics Dashboard - from: 2025-11-10T05:09:39Z (original: 2025-11-10 05:09:39.000)
Analytics Dashboard - to: 2025-11-17T05:09:39Z (original: 2025-11-17 05:09:39.000)
Analytics API - Error: DioExceptionType.badResponse
Analytics API - Error status: 500
Analytics API - Error data: {"error":"internal error"}
```

### Решение:

Если ошибка 500, проблема на стороне сервера. Нужно:
1. Проверить логи сервера
2. Проверить подключение к базе данных
3. Проверить SQL запросы в endpoint `/analytics/dashboard`
4. Убедиться, что все необходимые таблицы и views существуют
