# Исправление ошибки "code invalid" на Android

## Проблема
После прохождения reCAPTCHA код приходит, но при вводе появляется ошибка "code invalid".

## Что было исправлено:

### 1. Очистка кода от лишних символов
- Код теперь автоматически очищается от пробелов и других символов
- Остаются только цифры

### 2. Улучшенное поле ввода кода
- Максимум 6 символов (стандартная длина SMS кода)
- Только цифры (автоматическая фильтрация)
- Улучшенная читаемость (большой шрифт, увеличенное расстояние между цифрами)

### 3. Обработка ошибок
- `invalid-verification-code` - неверный код
- `session-expired` - сессия истекла (автоматический сброс)
- `invalid-verification-id` - ошибка верификации (автоматический сброс)

### 4. Защита от конфликта автоматической верификации
- На Android может происходить автоматическая верификация
- Если автоматическая верификация произошла, поле для ввода кода не показывается
- Это предотвращает конфликт между автоматической и ручной верификацией

### 5. Логирование для отладки
Добавлены debug-сообщения:
- `Verifying code: ...` - код, который верифицируется
- `Verification ID: ...` - ID верификации
- `Verification error: ...` - ошибки верификации

## Как проверить:

1. Запустите приложение с отладкой:
```bash
flutter run --debug
```

2. Откройте консоль и смотрите логи:
- При отправке SMS: `Sending SMS to: ...`
- При получении кода: `Code sent, verificationId: ...`
- При верификации: `Verifying code: ...`
- При ошибке: `Verification error: ...`

3. Проверьте:
- Код вводится только цифрами (без пробелов)
- VerificationId сохраняется правильно
- Нет конфликта с автоматической верификацией

## Возможные причины ошибки "code invalid":

1. **Код истек** (таймаут 60 секунд)
   - Решение: Запросите новый код

2. **Неверный формат кода**
   - Решение: Убедитесь, что вводите только 6 цифр

3. **Проблема с verificationId**
   - Решение: Проверьте логи, что verificationId сохраняется

4. **Конфликт с автоматической верификацией**
   - Решение: Уже исправлено в коде

5. **Проблема с Firebase**
   - Решение: Проверьте, что биллинг включен и SHA отпечатки добавлены

## Если проблема сохраняется:

1. Проверьте логи в консоли
2. Убедитесь, что:
   - Биллинг включен в Firebase
   - SHA-1 и SHA-256 добавлены в Firebase Console
   - Номер телефона в правильном формате (+7XXXXXXXXXX)
3. Попробуйте запросить новый код
4. Проверьте, что код не истек (таймаут 60 секунд)

## Дополнительная информация:

- Таймаут верификации: 60 секунд
- Длина кода: 6 цифр
- Формат номера: E.164 (+7XXXXXXXXXX)
