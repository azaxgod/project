# Включение биллинга в Firebase для Phone Authentication

## Проблема

Ошибка `billing_not_enabled` означает, что в вашем проекте Firebase не включен биллинг. **Phone Authentication требует включенного биллинга** для работы.

## Решение

### Шаг 1: Включите биллинг в Firebase Console

1. Перейдите на [Firebase Console](https://console.firebase.google.com/)
2. Выберите ваш проект `smsakimat`
3. Перейдите в **Project Settings** (⚙️ → Project settings)
4. Перейдите на вкладку **Usage and billing**
5. Нажмите **Modify plan** или **Upgrade project**
6. Выберите план **Blaze (Pay as you go)**
7. Подтвердите включение биллинга

### Шаг 2: Добавьте способ оплаты

1. В разделе **Usage and billing** нажмите **Add payment method**
2. Введите данные вашей кредитной карты
3. Подтвердите добавление

### Шаг 3: Проверьте лимиты Phone Authentication

После включения биллинга:
- **Бесплатный лимит**: 10 SMS в день для верификации (для тестирования)
- **Платные SMS**: После превышения лимита ~$0.06 за SMS (зависит от страны)

### Шаг 4: Настройте тестовые номера (опционально)

Для тестирования без расходов:
1. Перейдите в **Authentication** → **Sign-in method**
2. Нажмите на **Phone** провайдер
3. В разделе **Phone numbers for testing** добавьте тестовые номера
4. Для тестовых номеров SMS не отправляется, используется код `123456`

## Важно

- **Blaze план** имеет бесплатный лимит (Spark tier) для большинства сервисов
- Phone Authentication требует Blaze плана, но первые 10 SMS в день бесплатны
- После включения биллинга Phone Authentication начнет работать сразу

## Альтернативное решение (для разработки)

Если вы не хотите включать биллинг сейчас, можно:
1. Использовать тестовые номера в Firebase Console
2. Или использовать ваш собственный API для SMS (который уже реализован через `/auth/send-code`)

## Проверка

После включения биллинга:
1. Перезапустите приложение
2. Попробуйте отправить SMS-код
3. Ошибка `billing_not_enabled` должна исчезнуть
