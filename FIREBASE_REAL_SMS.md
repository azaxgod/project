# Как протестировать с настоящими SMS-кодами (не тестовыми)

## Что такое "10 SMS кодов"?

Firebase Phone Authentication предоставляет **бесплатный лимит 10 SMS в день** для верификации телефонных номеров. Это означает:
- Первые 10 SMS в день - **бесплатно**
- После 10 SMS - платно (~$0.06 за SMS, зависит от страны)

## Шаг 1: Включите биллинг в Firebase

### 1.1. Перейдите в Firebase Console
1. Откройте [Firebase Console](https://console.firebase.google.com/)
2. Выберите проект **smsakimat**

### 1.2. Включите Blaze план
1. Нажмите на **⚙️ (Settings)** в левом верхнем углу
2. Выберите **Project settings**
3. Перейдите на вкладку **Usage and billing**
4. Нажмите **Modify plan** или **Upgrade project**
5. Выберите план **Blaze (Pay as you go)**
6. Нажмите **Continue** и подтвердите

### 1.3. Добавьте способ оплаты
1. В разделе **Usage and billing** нажмите **Add payment method**
2. Введите данные вашей кредитной карты:
   - Номер карты
   - Срок действия
   - CVV
   - Имя на карте
   - Адрес
3. Нажмите **Save**

**Важно:** Даже с включенным биллингом первые 10 SMS в день остаются бесплатными!

## Шаг 2: Настройте Phone Authentication

### 2.1. Включите Phone провайдер
1. В Firebase Console перейдите в **Authentication**
2. Нажмите **Get started** (если еще не включено)
3. Перейдите на вкладку **Sign-in method**
4. Найдите **Phone** в списке провайдеров
5. Нажмите на **Phone**
6. Включите переключатель **Enable**
7. Нажмите **Save**

### 2.2. Настройте reCAPTCHA (для веба)
1. В настройках Phone провайдера убедитесь, что **reCAPTCHA verifier** включен
2. Для веба это необходимо для защиты от ботов

## Шаг 3: Протестируйте с настоящими SMS

### 3.1. Запустите приложение
```bash
flutter run -d chrome  # для веба
# или
flutter run            # для Android/iOS
```

### 3.2. Используйте настоящий номер телефона
1. Откройте страницу логина
2. Переключитесь на таб **"По номеру телефона"**
3. Введите **настоящий номер телефона** в формате +7XXXXXXXXXX
   - Например: +77001234567
   - **НЕ добавляйте номер в тестовые** (иначе будет использоваться тестовый код)
4. Нажмите **"Отправить код"**

### 3.3. Получите SMS
- На указанный номер придет **настоящее SMS** с кодом верификации
- Введите код из SMS
- Нажмите **"Подтвердить"**

## Как проверить использование лимита

### В Firebase Console:
1. Перейдите в **Usage and billing**
2. В разделе **Phone Authentication** вы увидите:
   - Количество отправленных SMS
   - Оставшийся бесплатный лимит
   - Стоимость (если превышен лимит)

### Пример:
- **День 1**: Отправлено 5 SMS → Осталось 5 бесплатных
- **День 2**: Отправлено 8 SMS → Осталось 2 бесплатных
- **День 3**: Отправлено 12 SMS → 10 бесплатных + 2 платных (~$0.12)

## Важные моменты

### ✅ Что работает с бесплатным лимитом:
- Первые 10 SMS в день - **бесплатно**
- Работает для всех номеров (не только тестовых)
- Лимит обновляется каждый день в 00:00 UTC

### ❌ Что НЕ работает без биллинга:
- Phone Authentication вообще не работает
- Ошибка: `billing_not_enabled`

### 💡 Рекомендации для тестирования:
1. **Используйте настоящие номера** для тестирования
2. **Следите за лимитом** в Firebase Console
3. **Используйте тестовые номера** только для разработки UI (код всегда `123456`)
4. **Для продакшена** убедитесь, что биллинг включен

## Проверка работы

После включения биллинга:
1. ✅ Ошибка `billing_not_enabled` исчезнет
2. ✅ SMS будут отправляться на настоящие номера
3. ✅ В Firebase Console будет видно статистику отправки

## Стоимость (после бесплатного лимита)

- **Казахстан**: ~$0.06 за SMS
- **Россия**: ~$0.05 за SMS
- **Другие страны**: см. [Firebase Pricing](https://firebase.google.com/pricing)

**Пример расчета:**
- 10 SMS в день = бесплатно
- 20 SMS в день = 10 бесплатных + 10 платных = ~$0.60 в день
- 100 SMS в день = 10 бесплатных + 90 платных = ~$5.40 в день

## Альтернатива: Ваш собственный API

Если не хотите использовать Firebase для SMS, можно использовать ваш существующий API:
- `/auth/send-code` - отправка SMS через ваш сервер
- `/auth/verify-code` - верификация кода

Это уже реализовано в вашем приложении и работает без биллинга Firebase.
