# Как протестировать с настоящими SMS-кодами

## Простое объяснение

### Что такое "10 SMS кодов"?
Firebase дает **бесплатно 10 SMS в день** для проверки номеров телефонов. Это значит:
- ✅ Первые 10 SMS в день = **бесплатно**
- 💰 После 10 SMS = платно (~$0.06 за SMS)

## Быстрая инструкция

### 1. Включите биллинг (5 минут)

1. Откройте [Firebase Console](https://console.firebase.google.com/)
2. Выберите проект **smsakimat**
3. Нажмите **⚙️** (Settings) → **Project settings**
4. Вкладка **Usage and billing**
5. Нажмите **Modify plan** → Выберите **Blaze (Pay as you go)**
6. Нажмите **Add payment method** → Введите данные карты
7. Готово! ✅

### 2. Используйте настоящий номер

1. Запустите приложение
2. Откройте страницу логина
3. Таб **"По номеру телефона"**
4. Введите **настоящий номер** (например: +77001234567)
5. Нажмите **"Отправить код"**
6. **На телефон придет настоящее SMS** с кодом
7. Введите код и подтвердите

### 3. Проверьте использование

В Firebase Console → **Usage and billing**:
- Видно сколько SMS отправлено
- Сколько осталось бесплатных
- Стоимость (если превышен лимит)

## Пример использования

**День 1:**
- Отправили 5 SMS → Осталось 5 бесплатных ✅

**День 2:**
- Отправили 8 SMS → Осталось 2 бесплатных ✅

**День 3:**
- Отправили 12 SMS → 10 бесплатных + 2 платных (~$0.12) 💰

## Важно!

- ✅ **Биллинг нужен** для работы Phone Authentication
- ✅ **Первые 10 SMS в день бесплатно** (даже с биллингом)
- ✅ **Лимит обновляется каждый день** в 00:00 UTC
- ❌ **Без биллинга** Phone Authentication не работает

## Альтернатива: Ваш собственный API

У вас уже есть свой API для SMS (`/auth/send-code` и `/auth/verify-code`), который работает **без биллинга Firebase**. 

Если хотите использовать его вместо Firebase, можно:
1. Использовать существующий `SmsPage` (использует ваш API)
2. Или изменить `PhoneLoginWidget` чтобы использовать ваш API вместо Firebase

Подробнее см. `FIREBASE_REAL_SMS.md`
