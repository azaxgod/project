## ⚠️ Проблемы и несоответствия

### 1. КРИТИЧНО: Неправильный формат ответа API

**Документация говорит:**
```json
{
  "timestamp": "2025-11-16T18:21:05Z",
  "vehicles": [
    {
      "vehicle_id": "...",
      "plate_number": "...",
      "contractor_id": "...",
      "contractor_name": "...",
      "last_gps": {
        "lat": 54.882345,
        "lon": 69.157890,
        "captured_at": "2025-11-16T18:21:03Z",
        "speed_kmh": 19.7,
        "heading_deg": 45.3,
        "is_simulated": true
      },
      "last_ticket_id": "...",
      "last_cleaning_area_id": "...",
      "last_polygon_id": "...",
      "status": "IN_TRIP"
    }
  ]
}
```

**Текущая реализация:**
```dart
// operations_collection.dart:550
return response.data['data'] as Map<String, dynamic>;
```

**Проблема:** Operations Service оборачивает ответ в `{"data": {...}}`, но формат должен быть:
```json
{
  "data": {
    "timestamp": "...",
    "vehicles": [...]
  }
}
```

**Текущий код ожидает:**
```dart
final vehicles = (data['vehicles'] as List<dynamic>)
```

**Нужно проверить:** Правильно ли парсится ответ с учетом обертки `data`.
