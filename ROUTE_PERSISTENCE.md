# Сохранение состояния при обновлении страницы

## ✅ Реализовано:

### 1. Сохранение текущего роута
- Создан `RouteStorage` для сохранения последнего роута
- На вебе: используется `localStorage`
- На мобилке: используется `SharedPreferences`
- Роут сохраняется автоматически при каждой навигации

### 2. Восстановление роута при обновлении
- При обновлении страницы (F5 на вебе или перезапуск на мобилке)
- Если пользователь авторизован → восстанавливается сохраненный роут
- Если сохраненного роута нет → используется `/dashboard`

### 3. Сохранение авторизации
- Firebase Auth автоматически сохраняет состояние через `FirebaseAuth.instance.currentUser`
- При обновлении приложения пользователь остается авторизованным
- `AuthNotifier` проверяет Firebase Auth при старте и восстанавливает пользователя

### 4. Очистка при выходе
- При выходе из аккаунта (`logout`) очищается сохраненный роут
- При переходе на `/login` также очищается сохраненный роут

## 📁 Файлы:

- `lib/core/storage/route_storage.dart` - основной файл (conditional exports)
- `lib/core/storage/route_storage_web.dart` - реализация для веба (localStorage)
- `lib/core/storage/route_storage_mobile.dart` - реализация для мобилки (SharedPreferences)
- `lib/core/storage/route_storage_stub.dart` - заглушка для других платформ

## 🔧 Как это работает:

1. **При навигации:**
   - GoRouter listener отслеживает изменения роута
   - Сохраняет текущий роут в `RouteStorage`
   - Работает асинхронно, не блокируя навигацию

2. **При обновлении страницы:**
   - `AuthNotifier` проверяет `FirebaseAuth.instance.currentUser`
   - Если пользователь авторизован → восстанавливается из Firebase
   - `redirect` в GoRouter проверяет сохраненный роут
   - Если сохраненный роут валидный → перенаправляет на него
   - Если нет → использует `/dashboard`

3. **При выходе:**
   - `logout()` очищает Firebase Auth
   - Очищает сохраненный роут через `RouteStorage.clearLastRoute()`
   - Очищает токены (если они были)

## ✅ Результат:

- ✅ При обновлении страницы (F5) пользователь остается авторизованным
- ✅ Пользователь остается на той же странице, где был
- ✅ Работает на вебе и мобилке
- ✅ При выходе все очищается корректно
